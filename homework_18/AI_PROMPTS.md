# AI Prompts

## 1. Code Review

Проведи code review этого Django view.

Проанализируй:
1. читабельность и структуру коду;
2. обробку GET і POST запитів;
3. використання database transaction;
4. створення Order та OrderItem;
5. відправку email;
6. обробку помилок;
7. відповідність Django best practices;
8. тестованість коду.

Не переписуй весь код без необхідності.
Спочатку переліч проблеми та запропонуй конкретні покращення.
Враховуй, що це навчальний Django-проєкт.

## 2. Генерация тестов моделей

Сгенеруй pytest-тести для моделей Django-проєкту.

Потрібно перевірити:
- створення об'єктів;
- основні поля моделей;
- зв'язки між моделями;
- коректність значень;
- основні методи моделей.

Використовуй pytest-django та factory-boy.
Тести повинні бути простими, зрозумілими та придатними для навчального проєкту.

## 3. Docstrings для views

Додай зрозумілі docstrings до всіх views Django-проєкту.

Для кожного view коротко опиши:
- його призначення;
- що він робить;
- основний результат роботи.

Не змінюй логіку views.
